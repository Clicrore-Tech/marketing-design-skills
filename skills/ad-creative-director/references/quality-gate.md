# Quality gate

Run `scripts/gate.py` for the mechanical checks, then score these ten questions on the actual pixels, full size and at 360px wide. Each is 0, 1 or 2. Deliver at 16 or more with no zero on questions 1 to 4.

| # | Question | 2 means |
| --- | --- | --- |
| 1 | **Thumb stop** | At 360px, something makes you pause within half a second |
| 2 | **First read** | Everyone would read the same thing first and it is the intended thing |
| 3 | **Legibility** | Headline and CTA readable at 360px without zooming |
| 4 | **Truth** | Every claim is real, sourced and consented |
| 5 | **Idea** | Cover the text: the image still says something about this topic |
| 6 | **Brand** | Recognisably this client without the logo being huge |
| 7 | **Originality** | It does not look like the competitors in the same feed |
| 8 | **One ask** | One action, obvious how to take it |
| 9 | **Craft** | No artefacts, bad hands, jagged cutouts, misspellings or broken script shaping |
| 10 | **Platform fit** | Safe zones respected, right size, right file weight |

Write the scores in the delivery note. If you could not view the image (no vision or no render), say the visual review is incomplete.
